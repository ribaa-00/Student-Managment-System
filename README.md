# Student Attendance Management System

A command-line based Student Attendance Management System built in C. The project provides separate Admin and Teacher access, attendance record management, and an interactive menu-driven interface.

## Features
- Admin Login
- Teacher Login
- Attendance Management
- Record Viewing
- Menu-Driven Interface
- File Handling (if implemented)

## Technologies Used
- C Programming Language
- GCC Compiler
- VS Code
